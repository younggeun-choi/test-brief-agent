## 2. OpenAI Launches ChatGPT Health Again (전체 미국 사용자 확대)
- 출처: https://propakistani.pk/2026/07/24/openai-launches-chatgpt-health-again/
- 발행: 2026-07-24
- 본문:
  On July 23-24, 2026, OpenAI officially launched its Health in ChatGPT feature for users in the United States, expanding the feature beyond the limited pilot launched in January.
  The rollout covers logged-in users aged 18 and older on ChatGPT Free, Go, Plus and Pro plans, available on the web and iOS.
  OpenAI says the gradual rollout may take several weeks to reach every eligible account.
  The service allows individuals to securely link their Apple Health data and medical records, enabling ChatGPT to provide personalized insights regarding health information.
  Over 300 million users engage with the AI chatbot weekly for health inquiries.

## 7. Anthropic Releases Claude Security Plugin for Claude Code in Beta
- 출처: https://cybersecuritynews.com/anthropic-claude-security-plugin/
- 발행: 2026-07-23
- 본문:
  Anthropic unveiled the Claude Security Plugin for Claude Code on July 23, 2026, released in beta for all Claude Code users.
  The plugin functions as a multi-agent vulnerability scanner that works right in the terminal, letting developers spot and fix potential security vulnerabilities while they're coding.
  Teams can scan recent changes or full repositories from the terminal, using the same Claude inference they already run.
  This follows an earlier limited research preview launched February 20, 2026, before expanding to a public beta for Enterprise customers by late April 2026.
